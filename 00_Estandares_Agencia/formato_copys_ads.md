# Estándar de Agencia — Formato de Copys para Anuncios (Ads)

Reglas globales para Meta Ads, Google Ads y cualquier pauta digital. El ADN del cliente define el tono; esto define el **formato**.

## Estructura de un copy de ad (Meta/Instagram)

1. **Gancho (primera línea)** — debe funcionar solo, sin el resto del copy visible ("ver más"). Pregunta, dato sorprendente o problema directo.
2. **Cuerpo** — 2 a 4 líneas máximo. Beneficio concreto, no lista de características.
3. **Prueba o diferenciador** — un dato verificable (garantía, entrega, testimonio corto).
4. **CTA único** — un solo verbo de acción, coherente con el botón del anuncio (no prometer "compra" si el botón dice "Enviar mensaje").

## Variantes obligatorias

- Mínimo **3 variantes por intención** (ej: precio, urgencia, prueba social) para evitar fatiga de audiencia y penalización por baja relevancia.
- Cada variante se guarda en el mismo archivo bajo un encabezado `## Variante A / B / C`.

## Reglas no negociables

- Nunca usar superlativos no verificables ("el mejor", "número 1") salvo que el cliente lo tenga certificado en su ADN.
- Nunca prometer precio, plazo o disponibilidad que no esté confirmado en `05_Campanas_Activas/` o por el humano.
- Un emoji máximo por línea, y solo si el ADN del cliente lo permite (`01_brand_guidelines.md` → moduladores de tono).
- El link de destino (WhatsApp, landing) debe llevar contexto precargado cuando la plataforma lo permita.
- Todo copy con oferta de precio requiere confirmación explícita del humano antes de pautarse (no se activa presupuesto sin aprobación).

## Guardado

Cada set de copys se guarda en `Cliente/04_Paid_Media_y_Funnels/Meta_Ads/` o `Google_Ads/` según el canal, con nombre `AAAA-MM-DD_NombreCampana_Copys.md`.
